# 🧮 Calculadora Básica en Java

Repositorio de la práctica de desarrollo de una calculadora interactiva por consola, implementando validaciones de entrada de datos y estructuras de selección, desarrollado para la materia de Computación en Java.

## 🛠️ Características del Programa
El programa interactúa con el usuario solicitando valores numéricos y ofrece un menú de opciones procesado mediante una estructura `switch` para realizar las siguientes operaciones:
- Suma, Resta, Multiplicación y División.
- Elevación al cuadrado de los valores ingresados.

**Validaciones Técnicas Integradas:**
- Implementación del método `.hasNextFloat()` para proteger el programa, forzando al usuario a ingresar números válidos y evitando que la ejecución falle si se ingresa texto por error.
- Prevención de excepciones matemáticas (como la división entre cero).
